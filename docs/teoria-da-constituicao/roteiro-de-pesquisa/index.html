Antes de começar

Este roteiro conduz vocês, passo a passo, até um mini plano de pesquisa. São seis etapas curtas. No fim, o texto sai pronto para copiar e enviar por e-mail ao professor. Nada aqui é salvo em servidor nenhum: se fechar a página, o trabalho se perde. Copiem o resultado no fim.

Escrevam ao menos um nome para continuar.

Etapa 1 · O objeto

O tema desta unidade já está dado: neoconstitucionalismo e constitucionalização do Direito no Brasil, a partir do texto de Barroso. Tema, porém, é largo demais para pesquisar. O que se pesquisa é um objeto: dois ou três termos conceituais combinados, que recortam o tema. Escolham o recorte que mais interessa a vocês.

Escolham um objeto para continuar.

Etapa 2 · O problema

O problema é a pergunta que a pesquisa vai responder — a parte mais importante do trabalho. Mudar o problema muda a pesquisa inteira. Abaixo há quatro perguntas já formuladas para o objeto que vocês escolheram. Podem adotar uma delas ou escrever a sua.

Escolham ou escrevam um problema para continuar.

Etapa 3 · As problematizações

Problematizações são perguntas menores que ajudam a responder a pergunta maior. Cada uma vira, mais adiante, um objetivo específico. Marquem duas ou três.

Marquem ao menos duas problematizações.

Etapa 4 · A hipótese

Hipótese é a resposta que vocês imaginam antes de investigar. Não precisa estar certa: precisa ser curta, sensata e clara o bastante para poder ser desmentida pela leitura. É ela que dá direção ao trabalho.

Escolham ou escrevam uma hipótese para continuar.

Etapa 5 · Os objetivos

O objetivo geral é responder ao problema. Os objetivos específicos são o caminho até lá: um para cada problematização. O que muda o sentido de um objetivo é o verbo. Escolham com atenção — cada verbo promete um tipo diferente de resultado.

Escolham um verbo para cada objetivo.
