## Site da disciplina

O conteúdo público do repositório fica na pasta `docs/`, preparada para publicação por GitHub Pages.

Após publicar o repositório no GitHub, habilite o Pages em:

`Settings > Pages > Build and deployment > Deploy from a branch > main > /docs`

Endereço esperado:

`https://wildpoxx.github.io/direito-constitucional/`

## Documentos institucionais

## Organização inicial

- `docs/`: site HTML para acesso dos alunos.
- `atividades/`: propostas de atividades em sala ou extraclasse.
- `jurisprudencia/`: seleção de julgados e materiais jurisprudenciais.
- `materiais-complementares/`: leituras, roteiros e materiais auxiliares.
